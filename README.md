# 阴阳师小助手（MoYomi）

一个面向 Windows 与 MuMu 模拟器的《阴阳师》日常任务辅助工具。

项目使用 Flet 提供桌面界面，通过 ADB 控制模拟器，并使用 OpenCV 模板匹配和本地 PaddleOCR 模型识别游戏画面。当前界面与模板按 **1280 × 720** 分辨率制作。

## 主要功能

- 多账号及 IOS/Android 角色独立配置
- 所有大账号均可按系统独立启用砂狐乐园，自动切换区服并合并显示悬赏状态
- 邮件领取、一键日常、悬赏检测、奸商检测和好友点赞
- 协战奖励、经验妖怪、寮麒麟和同心队
- 剧情跳过、一键秘闻等独立小工具
- 任务状态记录、运行日志、失败恢复和统一报错截图

## 运行要求

- Windows
- Python 3.12
- MuMu 模拟器
- 游戏分辨率：1280 × 720
- 可用的 MuMu ADB 连接

OCR 使用项目根目录下的本地 `models` 模型，无需在线下载模型。

## 安装

建议在项目目录创建虚拟环境后安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 启动

双击 `start_ui.bat`，或者在项目目录执行：

```powershell
.\.venv\Scripts\python.exe ui.py
```

首次使用时，请在“设置”页面选择：

- MuMu 安装目录
- `adb.exe` 路径
- 正在运行的 MuMu 实例

随后可分别配置每个账号及 IOS/Android 角色需要启用的任务。

## 代码结构

- `controller/`：状态存储、到期调度、任务服务以及日常/周常运行器。
- `ui_app/`：Flet 组件、页面、主题、设置存储和 UI 运行时。
- `main.py`、`ui.py`：保留原命令和导入方式的兼容启动入口。
- `module/`：设备连接、截图、识图、点击、日志和恢复等公共能力。
- `tasks/`：日常、周常、登录与独立工具任务。
- `models/`：本地 PaddleOCR 模型（不纳入 Git）。
- `tasks/<任务>/res/`：该任务使用的 PNG 模板图片。
- `tasks/<任务>/assets.py`：带中文用途注释的图片、搜索区域、识别阈值和固定点击资源常量。
- `module/res/`：启动恢复和任务恢复共用的模板图片。
- `module/base/device.py`：任务统一使用的截图、识图、点击、滑动和按键接口。
- `error_screenshots/`：任务失败、异常或恢复失败时保存的现场截图，数量由全局设置控制。

## 使用提示

- 启动任务前，请确保游戏画面可以正常操作并使用 1280 × 720 分辨率。
- 运行过程中不要同时手动操作模拟器，以免影响识图和点击。
- 同心队需要先为角色选择“队长”或“成员”身份。
- 账号状态、UI 设置与 Server酱发送状态保存在 `config/`；本机路径、OCR 模型和报错截图均属于本地文件，不会纳入 Git。
- 游戏界面更新后，部分模板可能需要重新适配。

本项目仅用于个人学习与自动化研究，请合理使用并自行承担使用风险。
