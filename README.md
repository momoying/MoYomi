# 阴阳师小助手（MoYomi）

一个面向 Windows 与 MuMu 模拟器的《阴阳师》日常任务辅助工具。

项目使用 Flet 提供桌面界面，通过 ADB 控制模拟器，并使用 OpenCV 模板匹配和本地 PaddleOCR 模型识别游戏画面。当前界面与模板按 **1280 × 720** 分辨率制作。

## 主要功能

- 多账号及 IOS/Android 角色独立配置
- 所有大账号均可按系统独立启用砂狐乐园，自动切换区服并合并显示悬赏状态
- 邮件领取、一键日常、悬赏检测、奸商检测和好友点赞
- 协战奖励、经验妖怪、寮麒麟和同心队
- 剧情跳过、一键秘闻等独立小工具
- 任务状态记录、运行日志和超时恢复

## 运行要求

- Windows
- Python 3.12
- MuMu 模拟器
- 游戏分辨率：1280 × 720
- 可用的 MuMu ADB 连接

OCR 使用项目根目录下的本地 `modle` 模型，无需在线下载模型。

## 安装

建议在项目目录创建虚拟环境后安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 启动

双击 `start_ui.bat`，或者在项目目录执行：

```powershell
.\.venv\Scripts\python.exe ui.py
```

首次使用时，请在“设置”页面选择：

- MuMu 安装目录
- `adb.exe` 路径
- 正在运行的 MuMu 实例

随后可分别配置每个账号及 IOS/Android 角色需要启用的任务。

## 使用提示

- 启动任务前，请确保游戏画面可以正常操作并使用 1280 × 720 分辨率。
- 运行过程中不要同时手动操作模拟器，以免影响识图和点击。
- 同心队需要先为角色选择“队长”或“成员”身份。
- 账号状态与 UI 设置保存在 `config/`；本机路径、OCR 模型和错误截图均属于本地文件，不会纳入 Git。
- 游戏界面更新后，部分模板可能需要重新适配。

本项目仅用于个人学习与自动化研究，请合理使用并自行承担使用风险。
